# InterHouse Sports Day - Event Catalog

_Date: 2026-05-16_
_Status: draft menu for Roblox sport/game selection_

## Purpose

List possible events for InterHouse Sports Day so the first campus can feel broad without trying to build every system at once.

Split:

- **Full games / full sports**: larger events with deeper mechanics, teams, rounds, or dedicated arenas.
- **Minigames / drills**: shorter activities, practice stations, support events, or simplified versions of bigger sports.

## Selection Rule

The first playable campus should expose variety, but only a few events need deep mechanics at launch.

Recommended split for Campus 001:

- 2-3 full sports
- 4-6 minigames/drills
- 1 House Spirit lane
- 1 Strategy lane

## Best First Campus Event Roster

Recommended v0.1/v0.2 roster:

### Full Sports

1. 100m Sprint
2. Long Jump
3. Table Tennis or Tennis
4. Football Penalty Shootout as a lightweight full event
5. Sigil Clash

### Minigames / Drills

1. Sprint Start Reaction
2. Baton Handoff
3. Takeoff Timing
4. Target Throw
5. Basketball Free Throw
6. Chant Timing
7. Banner Painting
8. Pattern Prediction

Why this mix:

- track/field honors the real inter-house sports root
- table tennis/tennis adds skill variety
- penalty shootout is immediately legible on Roblox
- Sigil Clash carries original InterHouse identity
- House Spirit events let non-athletic players matter

## Design Note

Do not make every event equally deep. The game should have:

- a few deep mastery sports
- many quick practice/support activities
- visible House contribution from both

That keeps the campus alive without delaying the core prototype forever.
